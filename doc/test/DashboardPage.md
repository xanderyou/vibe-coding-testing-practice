> 狀態：初始為 [ ]、完成為 [x]
> 注意：狀態只能在測試通過後由流程更新。
> 測試類型：前端元素、Mock API、路由導向

---

## [x] 【前端元素】應該正確渲染儀表板標題與登出按鈕
**範例輸入**：無
**期待輸出**：畫面上顯示「儀表板」標題與「登出」按鈕。

---

## [x] 【前端元素】當使用者角色為 admin 時，應該顯示管理後台連結
**範例輸入**：AuthContext 的 `user.role` 為 "admin"
**期待輸出**：導覽列顯示「🛠️ 管理後台」連結。

---

## [x] 【前端元素】當使用者角色不為 admin 時，不應該顯示管理後台連結
**範例輸入**：AuthContext 的 `user.role` 為 "user"
**期待輸出**：導覽列不顯示「🛠️ 管理後台」連結。

---

## [x] 【前端元素】應該正確顯示使用者名稱與角色標籤
**範例輸入**：AuthContext 的 `user.username` 為 "TestUser", `user.role` 為 "admin"
**期待輸出**：歡迎區塊顯示 "Welcome, TestUser 👋" 以及 "管理員" 的標籤。

---

## [x] 【Mock API】初始載入時，應該顯示載入中狀態
**範例輸入**：商品 API 請求尚未完成
**期待輸出**：商品列表區塊顯示 "載入商品中..."。

---

## [x] 【Mock API】成功從 API 取得資料後，應該正確渲染商品列表
**範例輸入**：商品 API 回傳包含數個商品的陣列
**期待輸出**：畫面上顯示各個商品的名稱、描述與價格。

---

## [x] 【Mock API】API 回傳錯誤且狀態碼不為 401 時，應該顯示錯誤訊息
**範例輸入**：商品 API 回傳狀態碼 500 與錯誤訊息 "伺服器錯誤"
**期待輸出**：商品列表區塊顯示 "⚠️ 伺服器錯誤"。

---

## [x] 【路由導向】點擊登出按鈕時，應該呼叫 logout 並導向至 /login
**範例輸入**：使用者點擊「登出」按鈕
**期待輸出**：呼叫 `logout` 方法，並導向至 `/login`。
